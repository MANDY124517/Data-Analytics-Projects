# 🐕 WeRateDogs: Multi-Source Data Wrangling & Viral Social Media Analytics

## Project Overview

In real-world data science, high-value insights are rarely packaged in clean, single-table spreadsheets. This project executes an end-to-end **Data Wrangling, Cleansing, and Exploratory Analysis** pipeline on data gathered from the viral Twitter account **@dog_rates** (also known as *WeRateDogs*, a community celebrated for humorously rating pet photos).

The project synthesizes disparate data sources—including manual flat files, programmatic HTTP downloads, and JSON API payloads—audits structural and quality defects, and builds an analysis-ready master dataset to reveal what drives viral engagement on Twitter.

## Data Wrangling & Quality Assurance

A comprehensive audit revealed **9 quality issues** and **4 structural tidiness issues** that were resolved using the **Define – Code – Test** framework:

### 1. Structural Tidiness Issues
- **Fragmented Relational Tables**: Unified the Twitter archive, neural network predictions, and tweet JSON metrics into a single denormalized master DataFrame.
- **Scattered Dog Categories**: Dog developmental stages (`doggo`, `floofer`, `pupper`, `puppo`) were split across separate dummy columns—consolidated into a single standardized `dog_stage` feature.
- **Combined Date & Time**: Separated composite timestamp strings into distinct date and hour components for temporal analysis.
- **Rating Deconstruction**: Combined numerator and denominator values into consistent mathematical rating metrics while filtering parsing artifacts.

### 2. Quality & Integrity Fixes
- **Erroneous Data Types**: Converted ID identifiers (`tweet_id`, reply IDs, user IDs) from float to string to prevent rounding; cast engagement metrics (`retweet_count`, `favorite_count`) to integers.
- **Malformed Ratings**: Fixed regex parsing issues where text containing multiple fractions (e.g., dates vs. actual scores) yielded incorrect rating numerators.
- **Invalid Dog Names**: Scrubbed false names extracted from lowercase articles and stopwords (`"a"`, `"an"`, `"the"`, `"none"`).
- **Extraneous HTML Tags**: Stripped HTML markup from the tweet source column to extract clean client metadata (iPhone, Web, TweetDeck).
- **Filtered Retweets**: Removed retweets and non-original posts to prevent double-counting engagement metrics.

## Key Analytical Insights

### 1. The Virality of Dog Stages
- Favorite counts consistently outnumber retweet counts across all categories by a factor of 2:1 to 3:1.
- Tweets featuring mature dogs categorized as **doggo** and young dogs as **puppo** achieved the highest median engagement and virality compared to standard listings.

### 2. Temporal Engagement Peaks
- Engagement analysis revealed distinct publishing activity peaks: **late-night hours (00:00–03:00)** and **end-of-workday hours (16:00–17:00)**.
- Evening and late-night posts demonstrated higher average retweet-to-favorite ratios, indicating a receptive, highly engaged audience during off-work hours.

### 3. Top Identified Dog Breeds
- After filtering unidentifiable and non-canine image predictions, the top three most frequently rated breeds were:
  1. **Golden Retriever**
  2. **Labrador Retriever**
  3. **Pembroke Welsh Corgi**
